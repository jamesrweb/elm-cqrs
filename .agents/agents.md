# Agent Guidelines - elm-cqrs

- Read `AGENTS.md` first. It points into this `.agents/` tree for everything
  else.
- The rules in `AGENTS.md` and in this tree are authoritative for this
  repository. Change them deliberately, in those files.
- Present a detailed plan and obtain explicit user permission before making any
  change, commit, or other alteration. Permission is per occasion and never
  carries forward.
- No changes without that permission, including commits, pushes, and workflow
  edits. Propose and wait when in doubt.
- This repository must stay self-sufficient for outside contributors. Do not
  reference the repository owner's personal global skills from anything in this
  tree.
